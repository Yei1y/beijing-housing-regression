# 北京市住房价格影响因素分析

## 项目概述

基于链家 2011–2017 年北京二手房成交数据（约 30 万条），运用多元回归分析方法探究住房价格的影响因素。项目涵盖 **数据预处理 → 探索性分析 → 变量选择 → 模型诊断 → 多模型比较** 的完整回归分析流程，旨在回答两个核心问题：

1. **哪些因素显著影响北京住房价格？** —— 通过变量选择和系数推断
2. **如何建立预测精度更高的回归模型？** —— 通过多模型比较与交叉验证

---

## 数据说明

### 数据来源

链家北京二手房成交记录，包含 26 个字段：地理位置（经纬度）、房屋属性（面积、户型、楼层、建筑类型、建筑结构、装修情况、梯户比等）、交易信息（成交时间、关注人数、挂牌天数等）以及目标变量 **单价（元/㎡）**。

### 原始数据质量问题

| 问题 | 涉及字段 | 处理策略 |
|------|----------|----------|
| Excel 损坏导致文本混入数值列 | `livingRoom`, `drawingRoom`, `bathRoom`, `constructionTime` | `pd.to_numeric(errors='coerce')` 强制转换 |
| 50% 缺失 | `DOM`（挂牌天数） | 中位数填充 + 缺失指示变量（DOM_missing） |
| 极端错误值 | `price` 最小为 1，`ladderRatio` 达千万级 | Winsorize 截尾处理 |
| 数据泄露 | `communityAverage`（社区均价）与目标高度相关 | 直接删除 |
| 约 6000 个类别 | `Cid`（社区 ID） | 直接删除 |

### 变量清单

**数值型**（16 个）：单价（price）、面积（square）、经纬度（Lng/Lat）、卧室数（livingRoom）、厅数（drawingRoom）、卫生间数（bathRoom）、建造年份（constructionTime）、梯户比（ladderRatio）、挂牌天数（DOM）、关注人数（followers）及衍生变量（距市中心距离、房龄、对数面积、对数关注人数等）

**分类型**（10 个，独热编码后生成 48 个虚拟变量）：建筑类型、建筑结构、装修情况、是否有电梯、是否近地铁、是否满五年、区域（15 个）、楼层类别、**交易年份（2011–2017，时间固定效应）**、**交易月份（1–12 月，月度固定效应）**

> 最终特征空间：**64 个特征**（16 个数值型 + 48 个虚拟变量），其中时间固定效应由 6 个年度虚拟变量和 11 个月度虚拟变量构成。

## 模型建立与评估（核心部分）

### 为什么选择线性回归框架？

本项目的目标兼具 **解释性**（哪些因素影响房价、影响方向和大小如何）和 **预测性**（模型能多准地预测房价）。线性回归在这两方面有天然优势：

- **可解释性**：系数直接反映边际效应
- **成熟的推断工具**：假设检验、置信区间、变量选择、诊断方法体系完整
- **与领域知识兼容**：住房价格的特征效应通常是可加或近似可加的

### 核心设定：双向固定效应模型

本研究采用 **时间和区域双向固定效应** 的半对数回归方程作为基准模型：

$$\log(Price_{it}) = \beta_0 + X_{it}'\beta + \gamma_t + \delta_k + \varepsilon_{it}$$

- $\gamma_t$：**时间固定效应**，由年度虚拟变量（trade_year_2012 至 trade_year_2017，2011 年为基期）和月度虚拟变量（trade_month_2 至 trade_month_12，1 月为基期）共同实现，灵活捕捉非线性的时间趋势和季节性波动
- $\delta_k$：**区域固定效应**（district_* 虚拟变量），控制不随时间变化的区域异质性

#### 为什么没把 trade_year 作为连续变量？

早期版本将 trade_year 作为连续线性变量纳入回归，这实质上施加了「年度价格增幅恒定」的约束。EDA 显示 2011–2017 年房价呈明显非线性特征——2015 年前平缓上涨、2015 年后加速攀升，因此用年份虚拟变量（时间固定效应）远优于线性趋势变量。修改后条件数从 7.84×10⁶ 降至 4.59×10⁵。

### 对数变换目标变量

对价格取自然对数后再建模，原因有三：
1. **缓解右偏**：原始偏度 ≈ 1.31，对数变换后降至 ≈ -0.59
2. **稳定方差**：对数变换将绝对差异变为相对差异，缓解异方差
3. **经济学解释**：系数 × 100 近似为半弹性

### 变量选择：共识策略

在高维特征空间（64 个特征，含时间固定效应）中，综合运用三种方法：

| 方法 | 选中变量数 |
|------|-----------|
| 向前选择（AIC） | 30 |
| 向后剔除（AIC） | 60 |
| LASSO（CV, alpha=0.0001） | 60 |
| **共识（≥2 种方法）** | **59** |

- 29 个变量被全部三种方法选中（高度稳健）
- 年份虚拟变量和多数月份虚拟变量被全票选中，验证了时间固定效应的必要性

### 模型诊断要点

| 诊断项 | 结果 |
|--------|------|
| VIF > 10 变量数 | 9 个（buildingStructure 系列、square/log_square、部分年份虚拟变量） |
| 最大 VIF | 492.4（buildingStructure_6） |
| 条件数 | 4.59×10⁵（原 7.84×10⁶，改善 94%） |
| Breusch-Pagan | p = 1.8×10⁻¹⁵⁹ → 拒绝同方差 |
| Goldfeld-Quandt | p = 0.857 → 不拒绝同方差 |
| Durbin-Watson | 1.966 → 无自相关 |
| HC3 下显著性改变 | **1 个变量**（原模型 3 个） |

### 多模型比较结果

比较了 6 种模型，关键数值变量从 6 个变为 5 个（trade_year 因转为虚拟变量不再参与多项式扩展）：

| 模型 | R² | RMSE（元/㎡） |
|------|:---:|:-------------:|
| **OLS + 多项式** 🏆 | **0.8294** | **9,411** |
| OLS + 交互项 | 0.8218 | 9,621 |
| OLS（全变量） | 0.8185 | 9,696 |
| Ridge（CV, alpha=0.49） | 0.8185 | 9,696 |
| OLS（筛选变量） | 0.8184 | 9,694 |
| LASSO（CV, alpha=1e-4） | 0.8180 | 9,710 |

**关键发现：**
- 加入时间固定效应后，基准 OLS 的 R² 从 0.786 提升至 **0.818**（+3.2 个百分点）
- OLS + 多项式模型预测最佳（R²=0.829），但高阶项导致系数膨胀至无法解释
- LASSO 在本应用中退化——64 个特征中多数与房价存在真实关联，稀疏性假设不成立
- 5 折交叉验证结果一致（CV R²=0.8295±0.002），排除过拟合
